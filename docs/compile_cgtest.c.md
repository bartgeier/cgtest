# Compile `cgtest.c`

## Linux
```
gcc cgtest.c -o cgtest
```
```
gcc -std=c89 cgtest.c -o cgtest
```

## Windows GCC
[https://winlibs.com/](https://winlibs.com/)  
*// if you don't know what to take, go with latest Windows 64-bit*
```
gcc cgtest.c -o cgtest
```
```
gcc -std=c89 cgtest.c -o cgtest
```

## Windows MSVC
```
cl cgtest.c
```
## macOs clang
```
clang cgtest.c -o cgtest
```
