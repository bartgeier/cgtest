# cgtest
A C unit test DSL compiler.

## Usage

```
cgtest --init <dir>      create cgtest-project.json, cgtest.h, and an example test inside <dir>
cgtest --config <path>   generate, compile and run cgtest-runner.c
cgtest --version         print the cgtest version
cgtest --help            print this message
```
